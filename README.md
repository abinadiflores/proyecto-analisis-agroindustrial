# Análisis de la producción y venta agroindustrial del Perú (2025–2026)

## Descripción
Proyecto académico de análisis de datos orientado al diagnóstico de calidad, limpieza, transformación y análisis exploratorio de datos de producción y venta agroindustrial del Perú.

## Objetivo
Identificar patrones de producción, ventas y utilización de materias primas mediante indicadores de desempeño y visualizaciones que apoyen la toma de decisiones sobre inventarios y planificación.

## Herramientas utilizadas
- Power BI
- Power Query (lenguaje M)
- DAX
- Python
- Pandas
- Matplotlib

## Estructura del proyecto
- `datos/`: conjunto de datos utilizado.
- `powerbi/`: panel de control y modelo de Power BI.
- `scripts/`: código y consultas de transformación.
- `informe/`: informe académico final.

## Reproducción del análisis
1. Descargar el conjunto de datos incluido en `datos/`.
2. Abrir el archivo `.pbix` con Power BI Desktop.
3. Verificar la ruta de origen del CSV en Power Query.
4. Actualizar las consultas y comprobar las medidas e indicadores.
5. Consultar el informe para conocer los criterios de limpieza y los resultados obtenidos.

## Fuente de datos
Plataforma Nacional de Datos Abiertos del Perú: https://www.datosabiertos.gob.pe/dataset/midagri-07-actividad-agroindustrial-ministerio-de-desarrollo-agrario-y-riego
